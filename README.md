# 실습 게시판 만들기

## 무엇을 하는 서비스인가
매일 실습갤러리를 올리는게 지겨워서 만들었습니다.
실습 개수만 넣으면 번호가 매겨진 실습 게시판이 만들어집니다.
게시판마다 결과물 사진과 한 줄 설명을 올리고, 올라온 결과물을 모아 볼 수 있습니다.

## 누구를 위한 것인가

나

## 어떻게 쓰나

1. 첫 화면에서 **시작하기**를 누릅니다.
2. **실습 개수**에 숫자를 넣고 **만들기**를 누릅니다.
   - 개수를 비우고 누르면 "몇 개를 만들지 숫자로 넣어 주세요" 안내가 나옵니다. **확인**을 누르면 다시 만들기 화면으로 돌아갑니다.
3. 게시판 목록에서 **실습 1**, **실습 2** … 중 하나를 누릅니다.
   - 칸마다 가장 최근에 올라온 사진과 올라온 개수가 보입니다.
   - **처음으로**를 누르면 만들기 화면으로 돌아갑니다.
4. 게시판 하나에서 결과물을 올립니다.
   - **사진 올리는 칸**에 사진 1장(png · jpg · jpeg)을 고르고, **한 줄 설명**을 넣은 뒤 **올리기**를 누릅니다.
   - 올리면 AI 한 줄 피드백이 함께 만들어집니다. 피드백이 없는 결과물에는 **AI 피드백 받기**를 눌러 만들 수 있습니다.
   - **내려받기**를 누르면 이 게시판에 올라온 결과물 목록을 CSV 파일로 받습니다.
   - **목록으로**를 누르면 게시판 목록으로 돌아갑니다.

### 첫 화면이 아닌 화면에서 늘 쓸 수 있는 것

- 왼쪽 사이드바
  - **첫 화면으로**: 첫 화면으로 돌아갑니다.
  - **답변 초안**: **문의 글**을 넣고 **말투**(정중하게 · 친근하게 · 간결하게)를 고른 뒤 **답변 초안 만들기**를 누르면 AI가 답변 초안을 만듭니다.
  - **지난 결과**: 펼치면 지금까지 받은 AI 답을 최근 것부터 볼 수 있습니다.
- 오른쪽 아래 🤖 아이콘
  - 누르면 대화창이 열리고 닫힙니다.
  - **말투**를 고르고 궁금한 점을 적으면 이 서비스에 대해 답합니다.
  - 답 옆의 📋를 누르면 답을 복사합니다.
