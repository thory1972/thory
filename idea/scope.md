# 만들 범위
## 넣을 기능 (셋까지)

1. [정리 버튼을 누르면 지금까지 모은 내용이 엑셀 파일로 저장된다] (핵심)
2. [카드사별 내역 파일을 넣으면 하나의 표로 합쳐진다]
3. [저장된 엑셀 파일을 다시 열면 지난주 내역에 이번 주 내역이 이어서 쌓인다]

## 뺄 기능

- [중복되거나 빈 줄을 지우는 버튼을 누르면 표가 깔끔하게 정리된다]

## 나중에 붙일 것

- [매주 같은 요일이 되면 이번 주 내역을 넣으라고 알려준다]
- [표를 날짜순으로 정렬하면 언제 많이 썼는지 순서대로 보인다]
- [합쳐진 표를 보면 카드별로 얼마 썼는지 합계가 바로 보인다]

## 한 번 써 보는 순서

1. 카드사별 내역 파일을 넣는다 → 하나의 표로 합쳐진다
2. 정리 버튼을 누른다 → 합쳐진 내용이 엑셀 파일로 저장된다
3. 다음 주, 저장된 엑셀 파일을 열고 이번 주 내역 파일을 넣는다 → 지난주 내역에 이번 주 내역이 이어서 쌓인 표가 나온다
4. 정리 버튼을 다시 누른다 → 쌓인 내용이 엑셀 파일로 다시 저장된다
5. 카드별로 얼마 썼는지 보려고 표를 보면 → 합계는 보이지 않는다 (막힘)
